# Google Sheets Decision Support Layer

This folder documents the Google Sheets component used as a visual and operational support layer for the project.

Main reference:

- Credit risk management sheet: [Google Sheets](https://docs.google.com/spreadsheets/d/1c2M-y9EaVsJferSnKHW8X4KZPHc7syRw1yLrfvo3NxQ/edit?gid=311571590#gid=311571590)

Role within the project:

- Review distributions and risk patterns visually
- Support early business interpretation
- Help identify outliers, missing values, and unusual profiles
- Complement the analytical workflow before building the predictive stage

Important note:

Several cleaning decisions documented in the notebook were informed by the patterns observed in this management sheet, especially those related to:

- unrealistic values
- incomplete records
- variables with limited analytical usefulness
- risk-oriented prioritization logic
